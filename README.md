# LinkUp — LinkedIn UI Clone (Project 08)

A responsive professional networking and job-discovery interface built with HTML, CSS, and vanilla JavaScript. This is an independent practice project, not the official LinkedIn website.

## Features
- Professional network-inspired layout with profile sidebar and feed
- Create a local demo post and interact with feed posts
- Search jobs by company, role, or skills
- Filter jobs by developer, internship, and data/QA categories
- Save/unsave jobs in the current page session
- Direct links to official employer career portals for role-specific searches
- Responsive desktop, tablet, and mobile layout

The role names are examples/categories, not verified live vacancies. Open the company portal and search the role title; confirm the job is currently open, location, eligibility, and deadline before applying.

## Run locally
1. Extract this project folder.
2. Open `index.html` in VS Code.
3. Use Live Server, or open the file in a browser.

## Deploy on GitHub Pages
1. Create a repository named `linkedin-ui-clone`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Add the published URL to your repository description.

## AI disclosure

## Limitations
This is a frontend-only demo. It does not authenticate users, submit applications, or connect to employer systems. Saved jobs and posts are not persisted after refresh.
